# 1.2 入力とコマンドの扱い

前節では、ユーザーからの入力を繰り返し受け付けるREPLを作成しました。しかし、この時点では入力された文字列は単なる文字列であり、プログラムはその意味を理解できません。

例えば、

```text
db > insert 1 Alice
```

という入力があったとしても、プログラムにとっては

```text
"insert 1 Alice"
```

という一つの文字列に過ぎません。

データベースとして動作させるには、この文字列を

* 実行するコマンド
* 操作対象のデータ

に分けて解釈する必要があります。

本書では、この役割を **SimpleParser** クラスが担当します。


## コマンドの分割

最初に、入力された文字列を空白で分割します。

例えば、

```text
insert 1 Alice
```

という入力は、

```text
["insert", "1", "Alice"]
```

という3つの要素に分割されます。

同様に、

```text
select
```

は

```text
["select"]
```

となります。

この処理は `SimpleParser` クラスの `parse()` メソッドで行っています。

```java
public String[] parse(String sql) {
    String[] tokens = sql.trim().split("\\s+");
    tokens[0] = tokens[0].toLowerCase();
    return tokens;
}
```

まず `trim()` を使用して入力の前後にある余分な空白を取り除きます。

その後、

```java
split("\\s+")
```

によって、1個以上の空白文字を区切り文字として文字列を分割します。

その結果、

| 入力               | 分割結果                     |
| ---------------- | ------------------------ |
| `insert 1 Alice` | `["insert","1","Alice"]` |
| `select`         | `["select"]`             |
| `delete 5`       | `["delete","5"]`         |

というように、コマンドと引数を個別に扱えるようになります。


## コマンド名を取得する

データベースが最初に知りたいのは、「どの操作を実行するのか」です。

そこで、分割した配列の最初の要素をコマンドとして取り出します。

```java
public String getCommand(String[] tokens) {
    return tokens.length > 0 ? tokens[0] : "";
}
```

例えば、

```text
["insert", "1", "Alice"]
```

であれば、

```text
insert
```

が返されます。

同様に、

```text
["select"]
```

であれば、

```text
select
```

が返されます。

これにより、以降の処理では入力全体を調べる必要がなくなり、コマンド名だけを見て処理を分岐できるようになります。


## コマンドに応じた処理の分岐

`start()` メソッドでは、取得したコマンド名をもとに処理を切り替えています。

```java
String[] tokens = parser.parse(scanner.nextLine());
String command = parser.getCommand(tokens);
```

取得したコマンドに対して、

```java
if (command.equals("insert") && tokens.length == 3) {
    insert(tokens[1], tokens[2]);
}
```

のように判定を行います。

例えば、

```text
insert 1 Alice
```

と入力すると、

```text
command = "insert"

tokens[1] = "1"

tokens[2] = "Alice"
```

となり、

```java
insert("1", "Alice");
```

が呼び出されます。

同様に、

```text
select
```

であれば、

```java
select();
```

が呼び出されます。

このように、入力された文字列を解析し、適切なメソッドへ処理を振り分けることで、データベースはさまざまな命令を実行できるようになります。


## エラー処理

ユーザーが必ず正しい形式で入力してくれるとは限りません。

例えば、

```text
db > hoge
```

のような未定義のコマンドを入力した場合は、

```text
Unknown command
```

と表示します。

また、

```text
db > insert 1
```

のように引数の数が不足している場合も、条件に一致しないため同様にエラーとなります。

このように入力内容を検査することで、誤ったコマンドによる異常な動作を防ぐことができます。


## この節のまとめ

この節では、ユーザーが入力した文字列を「コマンド」と「引数」に分割し、実行する処理を決定する仕組みを実装しました。

処理の流れをまとめると、次のようになります。

```text
ユーザー入力
      │
      ▼
"insert 1 Alice"
      │
      ▼
parse()
      │
      ▼
["insert", "1", "Alice"]
      │
      ▼
getCommand()
      │
      ▼
"insert"
      │
      ▼
insert("1", "Alice")
```

次節では、実際に `insert` と `select` を実装し、データベースへデータを登録・取得する機能を作成していきます。
