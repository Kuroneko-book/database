# 1.3 CRUD操作の実装

前節では、ユーザーが入力したコマンドを解析し、実行する処理を決定できるようになりました。

しかし、この時点ではデータベースとしての機能はまだありません。

そこで本節では、データベースの基本操作である **CRUD** を実装します。

CRUDとは、データを扱うための4つの基本操作の頭文字を取ったものです。

| 操作     | コマンド     | 説明       |
| ------ | -------- | -------- |
| Create | `insert` | データを登録する |
| Read   | `select` | データを取得する |
| Update | `update` | データを更新する |
| Delete | `delete` | データを削除する |

多くのデータベースは、これら4つの操作を基本として構成されています。本書でも、まずはこの最小限の機能を実装していきます。


## insert ― データを登録する

新しいデータを登録するには、`insert` コマンドを使用します。

例えば、

```text
db > insert 1 Alice
```

と入力すると、

```
キー：1
値：Alice
```

というデータをデータベースへ登録します。

REPLでは、コマンド名と引数の数を確認し、`insert()` メソッドを呼び出します。

```java
else if (command.equals("insert") && tokens.length == 3) {
    insert(tokens[1], tokens[2]);
}
```

ユーザー入力はすべて文字列として取得されるため、キーは `Integer.parseInt()` を利用して整数へ変換します。

```java
int id = Integer.parseInt(key);
```

もし数値以外が入力された場合は、

```text
db > insert abc Alice
Error: Key must be an integer.
```

のようにエラーメッセージを表示し、処理を終了します。

また、本書ではIDを一意に管理するため、すでに存在するキーは登録できません。

この判定には `HashMap` の `putIfAbsent()` を利用しています。

```java
if (db.putIfAbsent(id, value) != null) {
    System.out.println("Key already exists.");
    return;
}
```

登録に成功すると、

```text
Inserted.
```

と表示されます。


## select ― データを取得する

登録したデータを確認するには、`select` コマンドを使用します。

`select` には2つの使い方があります。

### すべてのデータを表示する

引数を指定しない場合は、登録されているすべてのデータを表示します。

```text
db > select
(1,Alice)
(2,Bob)
```

実装では、`HashMap` のすべての要素を順番に取り出して表示しています。

```java
db.forEach((id, name) ->
    System.out.println("(" + id + "," + name + ")"));
```

### 指定したデータを取得する

キーを指定すると、そのデータだけを取得できます。

```text
db > select 2
Bob
```

まずキーを整数へ変換し、

```java
if (!db.containsKey(id))
```

で存在を確認します。

存在する場合は

```java
System.out.println(db.get(id));
```

によって値を表示します。

存在しない場合は、

```text
Record not found.
```

と表示されます。


## update ― データを更新する

登録済みのデータを変更するには、`update` コマンドを使用します。

例えば、

```text
db > update 2 Robert
```

を実行すると、

```
ID = 2
```

のデータが

```
Bob
```

から

```
Robert
```

へ変更されます。

REPLでは、

```java
else if (command.equals("update") && tokens.length == 3) {
    update(tokens[1], tokens[2]);
}
```

として `update()` を呼び出しています。

更新処理では、まず対象のキーが存在するかを確認します。

```java
if (!db.containsKey(id)) {
    System.out.println("Record not found.");
    return;
}
```

存在する場合は、

```java
db.put(id, value);
```

によって値を上書きします。

更新が完了すると、

```text
Updated.
```

と表示されます。


## delete ― データを削除する

不要になったデータは、`delete` コマンドで削除します。

例えば、

```text
db > delete 1
```

を実行すると、

IDが1のレコードがデータベースから削除されます。

REPLでは、

```java
else if (command.equals("delete") && tokens.length == 2) {
    delete(tokens[1]);
}
```

として `delete()` を呼び出します。

削除処理も更新と同様に、まず対象のキーが存在するか確認します。

存在する場合は、

```java
db.remove(id);
```

によってレコードを削除します。

正常に削除されると、

```text
Deleted.
```

と表示されます。


## 動作確認

ここまで実装すると、データベースはCRUD操作を一通り実行できるようになります。

```text
Welcome to nekoDB!

db > insert 1 Alice
Inserted.

db > insert 2 Bob
Inserted.

db > select
(1,Alice)
(2,Bob)

db > update 2 Robert
Updated.

db > select 2
Robert

db > delete 1
Deleted.

db > select
(2,Robert)
```

登録したデータを取得し、更新し、不要になれば削除できることが確認できます。


## この節のまとめ

本節では、`HashMap` を利用してデータベースの基本機能であるCRUD操作を実装しました。ユーザーから入力されたコマンドは、対応するメソッドへ振り分けられ、`HashMap` に対して登録・検索・更新・削除が行われます。

この時点で、データベースとして最低限の機能は完成しています。しかし、データはすべてメモリ上の `HashMap` に保存されているため、プログラムを終了すると内容は失われてしまいます。

次節では、この `HashMap` がどのような役割を果たしているのかを整理し、第1章最後の課題である「データが永続化されない」という問題へとつなげていきます。
